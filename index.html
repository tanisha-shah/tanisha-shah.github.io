Active · Feb 2026 – Present
Federated Learning for Agricultural Disease Detection
Developing AgrifoldVGG — a custom VGG16 architecture with 1D Efficient Channel Attention modules trained across a simulated federated network for soybean leaf disease classification. The core challenge: achieving high accuracy on extreme non-IID distributions without centralizing sensitive farm data. Current results outperform baseline federated approaches on the 8,600+ image dataset.
📊 97.38% Test Accuracy · 0.974 Macro F1-Score · SCAFFOLD Algorithm
Federated LearningVGG16 + ECASCAFFOLDSAM SegmentationOpenCVNon-IID DataComputer Vision

Decentralized Intrusion Detection on HIKARI Dataset
Foundational federated research simulating a decentralized anomaly detection environment on the HIKARI network dataset. Applied PCA for dimensionality reduction, SMOTE for class balancing, and validated secure model aggregation using FedAvg — establishing the groundwork for the agricultural pipeline.
